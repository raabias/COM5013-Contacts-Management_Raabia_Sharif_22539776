# COM5013-Contacts-Management_Raabia_Sharif_22539776

## Project Overview

This project is a Contacts Management Application developed in Python for the COM5013 Algorithms and Data Structures module.

The application demonstrates how data structures and algorithms can be used to store, retrieve, modify and organise contact information efficiently.

## Main Features

The application allows users to:

- Add new contacts.
- Search for existing contacts.
- Update contact information.
- Delete contacts.
- Display stored contacts.
- Sort contacts alphabetically.

## Data Structures

The application uses a Python dictionary to store contacts. Dictionaries provide efficient access to records through unique keys.

Dictionary lookup, insertion and deletion typically have an average time complexity of O(1), although worst-case performance can be O(n).

## Algorithms

The application uses searching and sorting algorithms.

Linear Search can be used to search contacts by name, with O(n) time complexity.

Merge Sort is used to arrange contacts alphabetically. Its time complexity is O(n log n) in the best, average and worst cases.

## Programming Language

Python is used because it supports object-oriented programming and provides suitable built-in data structures.

## Running the Application

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open a terminal.
5. Run `python contacts_app.py` (or `python3 contacts_app.py` if required).

## Testing

The project includes `test_contacts.py` for automated testing.

Run the tests using:

`python -m unittest -v`

Testing covers core contact management operations and edge cases.
